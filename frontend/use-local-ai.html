Use Local AI

Run models on your own computer. No API cost, full privacy.

Step 1

Install a local model runner

Option A: Ollama (recommended)

Simple and fast setup. Mistral 7B is recommended — it's faster and more reliable than llama3.2 for textbook generation.

  1. Download Ollama
  2. Install it
  3. Open terminal
  4. Run the command below
ollama pull mistral

⚠ Avoid llama3.2 for textbook generation — it is significantly slower. Use mistral instead.

Option B: LM Studio

Graphical interface, no terminal needed.

  1. Download LM Studio
  2. Download a model (llama3 or mistral)
  3. Start the local server

Step 2

Start the local server

Ollama runs at: http://localhost:11434

LM Studio runs at: http://localhost:1234

Step 3

Connect in the app

  1. Go back to the main page
  2. Select "Use Local Model"
  3. Click "Check Connection"

Step 4

You are ready

Upload your file and generate textbooks - completely free.

Troubleshooting

  • Make sure Ollama is running
  • Make sure LM Studio server is started
  • Refresh the page
  • Restart the app if needed
